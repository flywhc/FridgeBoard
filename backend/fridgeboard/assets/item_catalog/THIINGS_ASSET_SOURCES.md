# Thiings 拟物图标来源

图标只对应一个不同的 Thiings 对象，下载后的 PNG 统一归一化为
`256×256 RGBA`，运行时仍通过 `theme_variants.json` 使用原有逻辑图标键。

[`/api/catalog`](https://www.thiings.co/api/catalog) 为准。详情页和原始图片
地址同时保留，便于后续重新下载或核对授权。
