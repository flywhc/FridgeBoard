# FridgeBoard 0.2.2

本版本新增 Android“今日食谱打卡”桌面小组件：可绑定冰箱，展示本周非空食谱，支持分页、手动刷新以及在小组件内完成或撤销完成食谱，并复用现有安全会话和同域接口。

同时接入小组件与前端周食谱的数据桥接、账号代次隔离、私有快照、一次性后台同步、认证失效处理和诊断日志约束；相关 Android 原生单元测试、前端回归测试、权限检查和正式签名 APK 校验已纳入发布门禁。

本版本包含生产服务器/PWA 和正式签名 Android APK。实际发布提交、release 标识、服务器镜像、数据库备份、健康检查、GitHub Actions 运行号及 APK 摘要将在发布完成后补充。
