# FridgeBoard 0.2.0

本版本将产品小版本号从 `0.1.9` 升级为 `0.2.0`，包含主入口代码拆分、页面缓存与静默后台刷新稳定性修复、用户级共享自定义分类与图标一致性修复，以及库存、食谱和购物清单相关回归修复。

本版本包含前后端测试、数据库迁移校验、lint、生产构建和 Android 权限检查，并发布同一版本的正式签名 Android APK。
