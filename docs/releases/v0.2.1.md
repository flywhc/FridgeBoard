# FridgeBoard 0.2.1

本版本修复库存数量归零后的日期展示和重新添加语义：数量为 0 的物品仍保留原添加时间与保质时间，从 0 恢复数量不重置时间，真正新增数量时才更新添加时间。

同时修复库存批次合并后的“最近添加”排序，完善周食谱完成/取消完成的乐观状态、缓存同步、防重复请求和失败回滚，并收紧 Android 会话故障处理：网络、存储和服务端异常不再自动清除 token 或跳转登录页，用户可查看原因并选择后续操作。

本版本包含对应的后端与前端回归测试、lint、构建、Android 权限和正式签名 APK 校验，并发布生产服务器与同版本 Android APK。

本次同版本补发进一步修复周食谱完成/取消完成请求期间的反馈：食谱行移动后，完成图标持续显示加载状态并暂时禁用按钮，服务端响应后恢复可操作状态；请求失败时回滚原状态和排序。
