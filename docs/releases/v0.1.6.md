# FridgeBoard 0.1.6

本版本集中完善了自定义小类的图标工作流：用户现在可以在图库、本地图片、在线搜索和 AI 生成之间更顺畅地准备候选图标，并在多个主题之间复用已选图标。候选生成过程提供连续的状态反馈，已完成的结果会立即显示，停止或失败时也会保留可用结果和明确的错误提示。

同时改进了在线图标服务的可靠性。图库支持分页浏览，在线目录具备本地缓存和网络异常回退，图片读取与搜索超时策略得到统一；AI 图片生成切换到 Agnes Image 2.0，并补充了更完整的请求、上游响应和异常链路日志，便于定位实际故障。

本版本还收紧了移动端图片处理和发布校验：前端构建、Android 权限审查、签名 APK 元数据校验及生产容器构建均纳入发布流程。
