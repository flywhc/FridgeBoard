# 新建小类多主题图标需求与界面设计

## 8. 实施备注

本实现已接入逻辑图标集主题变体表 `icon_asset_variants`，旧单文件资产迁移为
`ink` 变体。自定义小类的主题替换通过 copy-on-write 创建私有图标集；内置图标仍为只读。
运行时栅格图标在保留宽高比的前提下将最长边限制为 256px，SVG 使用元素/属性白名单校验。
在线搜索接口采用 Iconify 正式 API；Thiings 适配器在无稳定公开 API 时返回可识别的空结果并允许
回退本地导入。水墨 AI provider 使用文本模型输出受限 SVG，拟物/卡通继续使用 Agnes 图片模型。

状态：已确认，已实现并验证
日期：2026-08-26

## 1. 目标

重构“新建小类”的图标选择流程，使自定义小类可以为 `ink`、`skeuomorphic`、
`cartoon` 三个主题分别设置图标。切换应用主题时优先显示对应变体；对应变体不存在时，
借用该逻辑图标的其他主题变体，不显示破图。

系统内置小类及内置逻辑图标首期保持只读，不提供替换入口。自定义小类可以只替换当前主题，
且不得影响复用同一来源图标的其他小类。

## 2. 已确认产品边界

- 项目为个人、免费、无广告的 MIT 开源软件，用户自行下载、编译和运行。
- 自定义小类可维护一至三个主题变体；第一张确认的变体成为 `fallback_theme`。
- 当前主题缺失时按 `fallback_theme → ink → skeuomorphic → cartoon` 的稳定顺序解析。
- 新建流程默认打开当前应用主题，但主题标签只改变正在编辑的变体，不切换全局主题。
- 系统图标只允许被选择和借用，不允许原地修改。自定义小类基于系统图标替换时使用
  copy-on-write 私有逻辑图标集。
- 卡通主题支持图标库、本地导入、Thiings 在线搜索和分主题 AI 生成；在线入口沿用图片类主题的公开目录。

## 3. 图标来源

### 3.1 图标库

显示系统图标和当前冰箱已保存的自定义图标。选择系统图标时直接使用完整系统主题集；
后续为自定义小类替换某一主题时创建私有覆盖，不修改系统资源。

### 3.2 Android/iOS 本地图片

- Android“相册照片”使用系统 Photo Picker，“本机文件”使用 Storage Access Framework。
- iOS“相册照片”使用 `PHPickerViewController`，“本机文件”使用 `UIDocumentPickerViewController`。
- PWA 使用两个隐藏的 `input[type=file]` 作为降级入口。
- 接受 PNG、JPEG、WebP；HEIC/HEIF 在用户确认导入时无裁剪转为 PNG。
- 不自动裁剪、补边、抠图、调色、锐化或改变主体占比。
- 非正方形图片保持原宽高比，在固定图标容器内使用 `object-fit: contain`。
- 本地来源在选择入口上方固定显示四个候选位；图片处理完成后立即按顺序填充候选位，并将当前图片写入当前主题草稿。点击已有候选位会将该候选重新应用到当前主题；四个位填满后再次导入从第一个候选位循环覆盖。

### 3.3 Iconify（水墨主题）

后端调用 Iconify 正式 `/search` API，并按前缀批量读取 SVG 数据。搜索结果只保留单色、
许可证明确且适合小尺寸展示的集合。选中后由后端下载并执行 SVG 白名单清洗，禁止脚本、
事件属性、外链资源、`foreignObject` 和不受支持的 CSS。

### 3.4 Thiings（拟物主题）

Thiings 当前公开目录可以按英文名称和标签搜索，并可下载选中 PNG，但没有公开稳定的开发者
搜索 API。实现必须放在独立 provider 适配器后，并具备目录结构变化、下载失败和限流降级。

免费使用仍要求可见署名。应用在在线搜索页显示“3D 图标来自 Thiings”，并在第三方资源说明中
记录来源；不得把 Thiings 图标打包为可独立下载的素材库。

### 3.5 AI 生成

- AI 区继续保留现有“AI 模型”选择器，模型列表由服务端能力返回，不在页面写死。
- 当前只有 Agnes 时仍显示选择器并选中 `Agnes AI`；单一选项不可切换，但不移除控件，避免以后
  增加模型时再次改页面结构和交互契约。
- “AI 模型”标签与选择控件保持同行，选择控件沿用“未设主题时借用”的半宽布局。
- 模型按输出能力过滤：水墨主题只列出支持受限 SVG 文本输出的模型，拟物和卡通只列出支持
  图片生成的模型；同一 provider 可以为不同输出类型配置不同底层模型和端点。
- `ink`：调用文本 LLM 输出受限 SVG，而不是生成位图。模型只允许返回单个 SVG 文档，
  采用固定 `viewBox="0 0 64 64"`、透明背景、黑色单线、无文字和无外链。服务端使用 XML
  解析器校验元素与属性白名单，再生成 28px/48px 预览。校验失败的候选不展示。
- `skeuomorphic`：调用 Agnes 图片生成，提示词固定为透明背景、居中、Soft-3D 拟物、
  单主体、无文字、无边框，生成四个 PNG 候选。
- `cartoon`：调用 Agnes 图片生成，提示词固定为透明背景、平面色块、暖灰粗轮廓、
  简化形体、无文字和无复杂阴影，生成四个 PNG 候选。
- 客户端不能提交任意风格提示词，只提交小类名称和 `theme_key`。
- Agnes Image 2.0 图片接口当前为同步单图响应，没有公开的图片生成进度或中间画面事件；应用连续发起四次单图 `size: 1024x1024` 请求，并通过同域 SSE 逐张传递完成的候选。尺寸由 `FRIDGEBOARD_AGNES_IMAGE_SIZE` 覆盖，未完成的候选位使用本地动画表示等待，不能视为模型真实百分比。

## 4. 英语关键词生成

在线搜索前调用现有文本模型生成三至六个英语关键词，返回结构固定为：

```json
{
  "keywords": ["coconut milk", "coconut drink", "coconut carton"]
}
```

关键词必须为小写英文短语，不包含品牌、风格词、解释或标点。用户可以切换建议词，也可以手工
编辑搜索框。关键词按小类名称缓存在当前新建/编辑页面生命周期内，切换离开再回到在线页时复用
缓存，重新打开页面后才重新生成。生成期间在关键词显示区域显示纯文本“正在生成关键词”，不
改变底部保存按钮状态。请求失败或超时也在同一个关键词状态文本框显示错误文案。模型不可用时，
在线区显示可编辑输入框，不阻塞图标库、本地导入和 AI 生成。

## 5. 下载与尺寸处理

### 5.1 SVG

- 保存清洗后的原始 `viewBox` 和矢量路径，不进行栅格化缩小。
- 运行时由浏览器按 28px、40px、48px、56px 等目标容器缩放。
- 导入时验证 20px、28px 和 48px 预览，避免复杂路径在小尺寸不可辨认。

### 5.2 PNG/JPEG/WebP/HEIC

- 原始文件作为受鉴权源文件保留；另生成最长边 256px 的透明 PNG 或 WebP 展示资产。
- 只做等比缩放和必要格式转换，不裁剪、不补边。
- 建议上传上限 10MB、最大 1600 万像素；解码前后均检查大小，阻止解压炸弹。
- 运行时页面只加载 256px 展示资产，由 CSS 缩放到目标尺寸，不反复下载原图。
- 缩略图 URL 包含内容修订值，替换后不会继续显示旧缓存。

## 6. 页面与交互

### 6.1 页面骨架

继续使用标准二级页面壳：返回按钮、居中标题“新建小类”、关闭按钮、独立滚动内容区和底部
固定主操作。顶部将所属大类与小类名称放在同一行；页面内容顺序为小类名称、主题标签、三主题
图标槽位、选择来源和候选结果。

### 6.2 主题状态

- 主题标签显示 `拟物`、`水墨`、`卡通`，当前主题保持选中态。
- 主题标签下方固定显示三个对应主题的图标槽位。专用变体显示勾选；缺失变体自动展示已选择
  变体作为借用图标，并显示问号表示待确认；没有任何已选择变体时保留空槽位。
- 三主题槽位不再显示“当前主题未设置”或“将借用……”等状态文案。
- 借用状态只在新建/编辑小类页显示，日常库存页面不显示提示。

### 6.3 来源切换

来源使用四项分段控件：`图库`、`本地`、`在线`、`AI 生成`。在线标签下的 provider 由主题决定：

| 主题 | 在线来源 |
| --- | --- |
| 水墨屏 | Iconify |
| 拟物 | Thiings |
| 卡通 | Thiings |

在线搜索结果点击后直接写入当前主题草稿，并立即更新上方当前主题图标，不再提供额外的“使用此图标”确认按钮。
进入“在线”子页且尚无搜索结果时先显示四个占位位；搜索返回实际结果后再替换占位位，并显示对应的在线来源说明。
关键词建议始终保持单行横向滚动，超出内容区时可通过触摸滑动查看全部关键词。
关键词横向滚动区域不参与页面右滑返回手势，页面其他区域继续保留原有返回手势。

### 6.4 本地入口

“本地”页显示两个等宽命令按钮：“相册照片”和“本机文件”。选择完成后直接按顺序填入四个候选位，并
立即更新当前主题图标；点击候选位可切换当前主题图标，不额外显示图片预览或“使用此图片”确认按钮。

### 6.5 最终确认

底部“确认并创建小类”在名称为空或三个主题均无可解析图标时禁用。页面不再额外渲染三主题
汇总列表；确认操作原子创建小类、逻辑图标集和已选择变体。

### 6.6 新建与编辑模式

新建和编辑复用同一个 `SubcategoryEditor` 页面骨架、主题标签、来源切换、候选选择和尺寸预览，
但不能只替换页面标题：

| 语义 | 新建模式 | 编辑模式 |
| --- | --- | --- |
| 标题 | 新建小类 | 编辑小类 |
| 初始数据 | 名称可由添加物品流程带入，图标为空或借用 | 加载已保存名称、大类、fallback 和全部主题变体 |
| 草稿 | 新建图标草稿 | 基于已保存版本的修改草稿 |
| 底部操作 | 确认并创建小类 | 删除小类、保存修改 |
| 取消/返回 | 清理未确认候选，不创建小类 | 丢弃本次修改，保留服务器已有内容 |
| 提交 | 原子创建小类和逻辑图标集 | 原子更新名称/大类及发生变化的主题变体 |

编辑自定义小类时，切换主题后可以替换、补充或继续借用该主题图标。保存某主题变体不会删除未修改
的其他主题。若页面打开后没有任何变化，“保存修改”禁用。服务端使用版本号或更新时间防止旧页面
覆盖另一设备刚保存的修改。

编辑入口只对小类创建者显示；删除需要二次确认，且已有库存或食谱引用时由服务端拒绝，避免破坏历史数据。

系统小类不进入该编辑模式，也不显示“更换图标”入口；以后即使允许修改系统小类名称或排序，
系统逻辑图标仍必须由独立权限和接口控制。

## 7. 数据与接口摘要

`FoodCategory.icon_key` 保持不变。`icon_assets` 作为逻辑图标集，新增
`icon_asset_variants(icon_key, theme_key)`。变体记录媒体类型、存储路径、来源、来源 ID、来源 URL、
许可证、署名、内容修订和创建时间。

新建和编辑页面内的完整图标草稿只保存在前端内存中。上传、在线导入和 AI 候选在确认前只更新
前端候选状态；用户最终确认时，客户端才将全部变体提交到服务端的短期 `icon_draft` 暂存流程。
服务端暂存的上传、在线导入和 AI 文件在取消、失败或过期后清理；最终确认成功后移动到正式目录，
数据库回滚时保留旧文件并删除未提交新文件。

服务端下载外部资源时只允许预设 HTTPS 域名，限制重定向、响应时间、正文大小和媒体类型；
DNS 解析结果禁止落入本机或私网，避免 SSRF。日志不得记录图片正文、完整签名 URL 或密钥。

## 9. 已确认决策

1. 在线来源固定为“水墨 Iconify、拟物/卡通 Thiings”，三个主题均保留可选的“在线”入口。
2. Thiings 在在线搜索页显示短署名，并在“关于 → 第三方资源”保留完整说明。
3. 栅格展示资产最长边限制为 256px；原始文件继续受鉴权保留。
4. 水墨 SVG 使用严格的 64×64 单色线稿约束；校验失败时允许重新生成或选择 Iconify。
