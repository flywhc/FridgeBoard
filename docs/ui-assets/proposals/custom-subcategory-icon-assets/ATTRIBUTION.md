# 设计稿示例图标来源

本目录仅用于“新建小类多主题图标”本地设计稿，不构成可独立下载或再分发的图标素材库。

## Thiings

以下示例来自 [Thiings](https://www.thiings.co/)，按其免费、个人、非商业用途条款用于本项目
设计评审，并仅做等比缩放至 256×256 PNG：

- [Coconut](https://www.thiings.co/things/coconut)
- [Coconut Water Carton](https://www.thiings.co/things/coconut-water-carton)
- [Milk](https://www.thiings.co/things/milk)
- [Carton of Milk](https://www.thiings.co/things/carton-of-milk)

Thiings 使用条款：<https://www.thiings.co/terms>
