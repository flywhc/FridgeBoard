# 需求追踪与回归矩阵

状态：现行回归基线，RG-016、RG-018、RG-019、RG-020、RG-021、RG-022 待评审，其余场景已完成并验证
更新时间：2026-09-04
需求来源：[产品需求基线](product-requirements.md)

本文档把需求归并为稳定的回归场景。像素级样式调整不单独制造需求 ID；它们必须挂到受影响页面场景和 UI 设计资产上。

## 使用规则

- `PR-*` 表示产品需求，`RG-*` 表示可执行回归场景。
- 自动化证据记录测试入口或质量门禁；人工证据记录用户路径、设备和预期结果。
- 新增或修改行为时，先补 `PR-*` 和 `RG-*`，再实现；修复完成后更新状态和证据。
- 运行完整门禁前，先执行受影响场景；发布前执行全部自动化门禁及本次发布涉及的人工场景。

## 完整质量门禁

```bash
uv lock --check
uv run ruff check backend
uv run pytest
npm run --prefix frontend lint
npm run --prefix frontend test -- --run
npm run --prefix frontend build
docker build --tag fridgeboard:local .
git diff --check
```

仅文档变更无需重复运行应用门禁；交付时应运行 `git diff --check`，并说明未运行的项目。涉及前端行为、后端行为、发布或外部服务时，执行对应完整命令并记录结果。
