# 家常食橱拟物主题：全应用皮肤设计提案

状态：待评审；本提案不包含前端实现。  
目标：让“拟物”成为整个手机端的统一产品语言，而不是冰箱图和物品图标的局部效果。

## 1. 视觉方向

关键词：**温和厨房、搪瓷与磨砂塑料、整理有序、低饱和色彩**。

- 不使用真实厨房照片、木纹大背景、玻璃、发光或装饰性渐变。
- 页面不是“卡片堆叠”。背景是淡灰绿台面，内容按“柜门 / 托盘 / 标签条”三种实体层级组织。
- 阴影只表达可按压或浮起的实体：主按钮、输入框、底部导航、弹窗、冰箱预览。普通列表行只有压印分隔线。
- 3D 图标使用 Thiings：主导航、页面级入口、分类和空状态。微操作（返回、关闭、加减、菜单）继续使用同一套低饱和实体按钮中的简洁符号，避免 3D 图标挤占 48px 热区。
- 已有拟物冰箱和分类图标是冻结设计资产：全应用皮肤不得重绘、改色或以概念占位图替代它们。冰箱入口使用冰箱箱体图标；“我的”使用无性别人像图标；冰箱与橱柜共用设备管理入口。

## 2. 色彩与材质令牌

| 角色 | 色值 | 材质 / 用法 |
| --- | --- | --- |
| 应用背景 | `#E8ECE5` | 冷灰绿台面，连续背景 |
| 顶部与底部壳 | `#F5F1E8` | 暖白搪瓷边框，固定壳 |
| 内容托盘 | `#FCFAF4` | 米白瓷面，表单与弹窗 |
| 主操作 | `#71877A` | 鼠尾草磨砂塑料，白字 |
| 次操作 | `#E1E8DF` | 浅鼠尾草，深色文字 |
| 冷藏提示 | `#B9CED0` | 雾蓝，仅作温区和信息辅助 |
| 食谱提示 | `#D8C9AC` | 燕麦色，仅作计划标签 |
| 风险 | `#B86D5C` | 灰陶红，仍配合图形和文字 |
| 文字 | `#35434A` / `#6C7876` | 深蓝灰 / 辅助灰 |

圆角固定为 10px；实体边框为 1px 低对比描边；主控件为一层 2–4px 短阴影和 1px 内高光。按下只下移 1px，并变为内阴影。

## 3. 页面系统

### 一级页：首页、食谱、购物、我的

- 固定暖白搪瓷顶部栏，中心保留现有页面标题；右侧仅保留一个高频实体图标按钮。
- 固定底部导航改为四个等宽“浅凹槽”；当前页为鼠尾草压下态，配 Thiings 3D 图标，未选中图标降饱和但不灰掉。
- 主内容不再使用纯白空底：首页的冰箱预览放在雾蓝内胆托盘；食谱使用燕麦色日期条；购物使用米白清单纸面；我的使用浅灰绿分组标签。

### 库存与分区列表

- 每条物品作为一行“搪瓷标签条”，左侧 48px 分类图标位于浅色凹槽，文字信息保持两行密度。
- 数量控件是一体化的浅灰绿机械步进器；临期和过期使用纹理徽记与文字，不用高饱和底色覆盖整行。
- 筛选、搜索与多选状态共用一条浅凹工具带，避免额外浮卡。

### 添加与编辑物品

- 表单按“物品、日期、位置、备注”四个连续托盘分段，字段标签如冰箱收纳标签，输入面为内凹瓷面。
- 分类选择器是横向图标托盘；展开目录沿用同一托盘，不另造弹层视觉。
- 底部主操作区保持暖白搪瓷壳，主按钮为唯一饱和强调；扫描、识图、相册是三个等尺寸实体图标按钮。

### 食谱与补货

- 周切换使用两个相连的计划标签，而不是独立按钮组；当天标题为一条燕麦色标签条。
- 菜谱条目像贴在冰箱门上的配方标签：左侧 Thiings 食物图标，右侧食材筹码保持低对比；完成态转为压印对勾，不用大面积变灰。
- 补货清单复用库存的标签条和步进器，避免形成第二套视觉语言。

### 我的、设置、通知与弹窗

- 设置行不使用卡片，每个分组是一张连续的搪瓷清单；页面级入口使用 Thiings 图标，箭头与开关使用小型实体控件。
- 通知以风险类型的小色签标识，正文保持可扫描的列表密度。
- 弹窗是一张暖白“冰箱门便签”，顶部有独立关闭热区；确认 / 取消维持主次实体按钮层级。

## 4. 图标规则

- Thiings 图标统一导出透明底、同一光源、同一透视和 128px 源尺寸；显示尺寸限定为 28px（导航）、32px（入口）、48px（分类/空状态）。
- 选用圆润但非玩具化的厨房、盘子、购物车、个人资料、搜索、扫码、相机、设置、通知和冰箱图标；统一降饱和约 25%，不混用高饱和原图。
- 每个业务语义只绑定一个逻辑图标与三个主题变体；不在不同页面替换同一物品含义。
